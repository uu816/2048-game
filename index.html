      🎮 2048 游戏增强版

      2026.06

      使用原生 JavaScript 实现的经典 2048 游戏，采用 IIFE 模块化架构， 支持 4×4 和 5×5 两种网格模式，包含成就系统与排行榜。

      • 架构设计：将单文件重构为 9 个独立模块（Storage / Game / Tile / UI / Leaderboard / Achievements / Share / Navigation / App），通过 window.Game2048 命名空间通信，降低耦合度
      • 核心逻辑：实现方向键与触屏滑动两种输入方式，采用行/列翻转统一处理算法，支持方块合并动画、分数浮动提示、胜利/失败弹窗
      • 数据持久化：封装 Storage 模块统一管理 localStorage，处理 JSON 序列化和异常，保证最高分、排行榜、成就状态在刷新后不丢失
      • 排行榜系统：Top 10 记录保存，支持按分数和时间多维度排序，显示玩家昵称和网格大小
      • 成就系统：3 个成就条件（首次通关/满分挑战/速度之王），带解锁动画和持久化状态
      • 双主题支持：清新治愈（经典米色调）+ 暗黑赛博（霓虹渐变），CSS 变量驱动，一键切换
      • 响应式适配：桌面端方向键操作 + 移动端手势滑动，游戏棋盘按屏幕比例自适应
      • 分享功能：Clipboard API 生成分享文本，支持游戏成绩一键复制
      代码规模：3,900+ 行 模块数量：9 个 🎨 主题数量：2 套 支持平台：桌面 / 移动
