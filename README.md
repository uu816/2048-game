# 2048 小游戏

一个可部署到 GitHub Pages 的经典 2048 游戏。

## 游戏规则

- 使用方向键或 WASD 控制方块移动
- 相同数字的方块碰撞时会合并
- 达到 2048 即胜利

## 新增功能

- **本地排行榜**: 自动保存每次游戏的分数，显示历史最高记录
- **暂停功能**: 按 P 键或点击暂停按钮可暂停游戏
- **网格大小选择**: 支持 4×4 和 5×5 两种模式
- **游戏速度调整**: 支持快、正常、慢三种速度
