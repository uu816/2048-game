# 2048 小游戏

一个可部署到 GitHub Pages 的经典 2048 游戏。

## 游戏规则

- 使用方向键或 WASD 控制方块移动
- 相同数字的方块碰撞时会合并
- 达到 2048 即胜利

## 功能特性

### 基础功能
- **实时计分板**: 分数实时更新，带弹跳动画效果
- **最高分持久化**: 使用 localStorage 保存最高分，刷新页面不丢失
- **网格大小选择**: 支持 4×4 和 5×5 两种模式
- **游戏速度调整**: 支持快、正常、慢三种速度
- **暂停功能**: 按 P 键或点击暂停按钮可暂停游戏

### 视觉与动效
- **双主题皮肤**: 清新治愈风 & 暗黑赛博风
- **流畅动画效果**:
  - 新方块出现动画
  - 方块合并动画 + 光效
  - 得分飘字动画
  - 分数弹跳动画
  - 模态框入场动画
  - 2048 方块脉冲光效

### 进阶功能
- **本地排行榜**: 自动保存每次游戏分数，Top10 排名展示
- **触屏手势支持**: 完全兼容移动端触摸滑动操作
- **响应式设计**: 完美适配不同屏幕尺寸
